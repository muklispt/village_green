# Green Village 🌱

Green Village is an agriculture e-commerce web application that allows customers to browse and purchase agricultural products online.

The project also includes a separate admin panel for managing products, categories, customers, orders, payments, coupons, offers, reviews, and referrals.

## 📌 Project Overview

Green Village provides a simple and user-friendly platform for purchasing agricultural products online.

### Customer Features

- Customer registration and login
- Customer profile management
- Browse agriculture products
- Browse products by category
- Product search
- Product details
- Add products to cart
- Update cart quantity
- Remove products from cart
- Checkout
- Mandatory online payment
- View order history
- View order details
- Product reviews and ratings
- Apply coupons
- View product offers
- Referral system

### Admin Features

- Separate admin login
- Admin dashboard
- Product management
- Category management
- Customer management
- Order management
- Payment management
- Product review management
- Coupon management
- Offer management
- Referral management
- Admin profile management
